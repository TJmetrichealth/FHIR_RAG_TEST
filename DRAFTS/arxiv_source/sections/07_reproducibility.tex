\section{Reproducibility}
\label{sec:reproducibility}

\paragraph{Git tags.}
The dataset is frozen at tag \texttt{dataset-freeze-v1} (commit \texttt{98959f8};
applied 2026-05-05).  The full evaluation results are frozen at tag
\texttt{results-freeze-v1} (commit \texttt{338c4c9}).  The freeze manifest (\texttt{data/freeze.json})
records SHA-256 hashes of all 1,203 input files;
overall SHA-256:
\texttt{4d0da93e19c3071414ef5e1045d338104f9628842abe34f548aa050e9d0aa736}.

\paragraph{Raw evaluation JSONLs.}
The three raw evaluation files (\texttt{a.jsonl}, \texttt{b.jsonl}, \texttt{c.jsonl})
under \texttt{results/raw/} are not checked into the git repository (too large
for GitHub).  They reside locally in \texttt{results/raw\_large/} and can be
regenerated by:
\begin{verbatim}
python -m eval.harness --system {a|b|c} --concurrency 4
\end{verbatim}
\noindent Note: regeneration requires (a) a Groq API key with Developer-plan access
and (b) \texttt{eval/cache/} to be populated (cached responses are gitignored but
preserve byte-reproducibility; absent cache, the harness will recompute at API cost).
A \texttt{make reproduce} warning is printed when \texttt{eval/cache/} is empty.

\paragraph{Scoring and statistics.}
All downstream artefacts are reproducible from the raw JSONLs:
\begin{itemize}
  \item Scoring: \texttt{python -m eval.score}
    $\rightarrow$ \texttt{results/scored.csv}
  \item Statistics: \texttt{python analysis/run\_stats.py}
    $\rightarrow$ \texttt{analysis/results.md}
  \item Error taxonomy: \texttt{python analysis/run\_error\_taxonomy.py}
    $\rightarrow$ \texttt{analysis/error\_taxonomy.md}
  \item Feature arm: \texttt{python features/run\_feature\_arm.py}
    $\rightarrow$ \texttt{analysis/feature\_extraction.md}
\end{itemize}

\paragraph{Model identifiers.}
Narrative generation: \texttt{llama-3.3-70b-versatile} (Meta, via Groq free tier);
prompt hash \texttt{518bc71d87b7}.
Answer generation: \texttt{qwen/qwen3-32b} (Alibaba, via Groq Developer plan);
temperature 0.0, single run per question.
Embedding: \texttt{BAAI/bge-large-en-v1.5} (BAAI, via sentence-transformers, local CPU).

\paragraph{Hardware and environment.}
Embeddings and feature extraction: CPU (no GPU required).
Evaluation: Groq API (HTTP; local orchestration only).
Python 3.11; dependencies pinned in \texttt{requirements.txt}.
A Dockerfile is provided for environment reproducibility (decision C5).
