## 2. New concerns emerging from the revisions

### 2.1 The templated-narrative finding is underplayed

A-T beats A overall (41.3% vs 40.6%) with a paired-bootstrap CI that excludes zero. The framing in §4.10 and the Contribution list calls this "matches or slightly exceeds," which is technically accurate but understates the practical implication.

The substantive finding is **not** "narrative format wins, regardless of generator." It is closer to: *for this QA workload, an LLM narrative pipeline can be replaced by a deterministic template generator with no accuracy loss, and a small gain.* That has direct production consequences:

- No hallucination risk
- No LLM generation cost or latency
- Auditable, byte-deterministic narrative artifacts
- No prompt-iteration burden as upstream LLMs evolve

These are not incidental practitioner-facing points. They belong in §5 (Practical guidance) and probably in the Abstract. The current framing ("the narrative-format advantage is not driven by LLM-specific lexical regularity") is correct but defensive. The stronger framing ("deterministic template narratives are a drop-in replacement that wins on every operational axis without losing accuracy") is what a JAMIA reviewer would expect to see foregrounded.

### 2.2 The per-family heterogeneity in A-T is the more interesting story

Table 12 shows large per-family deltas that are being treated as a footnote:

- temporal_comparison: A-T **+10.21 pp** [+8.62, +11.75] (templated wins big)
- regimen_aggregation: A-T **-7.29 pp** [-8.92, -5.75] (LLM narrative wins big)
- cross_resource: A-T -2.25 pp [-4.25, -0.25]
- regimen_compliance: A-T +1.79 pp [+0.81, +2.79]

These are not subtle effects. The pattern is mechanistic and interpretable: templated narratives carry explicit dose-date tables (helps date matching for missed-dose detection); LLM narratives carry summarized counts and aggregate phrasing (helps dose-history aggregation). The claim in §5 that "the optimal narrative style is task-dependent" is the load-bearing finding here, not "narrative format is the load-bearing property."

This reframes the contribution from a single-axis finding ("narrative > structured") to a two-axis one ("narrative > structured, AND narrative-style choice matters within narrative"). The two-axis version is more interesting and more actionable. The current draft treats the second axis as a future-work item ("hybrid narratives... could outperform either single-style narrative on a workload mix"). It is in fact already demonstrated in the data: a per-family-optimal hybrid would beat both A and A-T on overall accuracy by construction.

Suggested action: promote the hybrid-narrative observation from a Discussion aside to a named finding, even if a hybrid system is not built in this paper.

### 2.3 The Methods section does not preview Systems N and A-T

§3.2 lists only Systems A, B, and C. Systems N and A-T are introduced for the first time in §4.9 and §4.10 respectively. A reader who reads sequentially is surprised twice. A brief "Additional arms" paragraph in §3.2 (after the C description) saying "Sections 4.9 and 4.10 report two further arms, N (no-retrieval baseline) and A-T (templated-narrative ablation), with all variables held constant except retrieved context and narrative source respectively" would fix this with no structural change.

### 2.4 Tier 3 recall@k numbers belong in a table

§5 reports Tier-3 recall@5 as: "cross_resource 89.7% / 99.7%, regimen_aggregation 83.2% / 94.1%, regimen_compliance 76.6% / 89.9%, and temporal_comparison 80.0% / 77.4% for B and C respectively." This is the empirical basis for the "Tier-3 collapse is a reasoning bottleneck, not a retrieval bottleneck" claim. It deserves a small table (5 family rows x 2 system columns) rather than inline prose. Same data, much more verifiable.

The temporal_lookup callout (C 76.5% vs B 78.0%; temporal pre-filter possibly over-pruning) is a sharp observation. Worth keeping but probably better in the table caption than mid-paragraph.

### 2.5 The Tier 3 interpretation has an internal tension

Two adjacent claims in §4.9 / §5 are in some tension:

- "Retrieval contributes a roughly uniform +13 pp across A, B, and C at Tier 3" (real retrieval signal)
- "Actively misled by retrieved context relative to a constant prediction strategy" (systems below modal baseline)

Both are true (retrieval adds signal, but the systems still underperform a trivial baseline), but the writing should reconcile them. Suggested phrasing: *retrieval adds real signal at Tier 3 (+13 pp vs no retrieval) but does not add enough signal to clear the within-family modal baseline; the residual gap is reasoning failure, not retrieval failure.*

### 2.6 The infeasibility argument for a non-tautological label is too quick

§5 and §6 say a Synthea-derived clinical-outcome label is not feasible "on the current cohort." This is honestly framed but the "current cohort" qualifier hides the fact that several non-trivial paths remain available without moving to real PSP data:

1. Regenerate Synthea with regimen-impact modules that emit adherence-dependent disease-progression events
2. Use a temporal holdout: predict a label derived from doses in days 90-180 using only features computed from days 0-90
3. Use a feature-holdout: predict the label using FS-Structured *minus* the gap statistics, vs FS-Narrative

Path 2 is particularly cheap and would directly test the dissociation on the same cohort. The Discussion's punt to "real PSP data follow-up" overlooks these. Suggested fix: add a one-sentence acknowledgment that within-Synthea label redesign is possible and is on the roadmap, alongside the real-data path.

### 2.7 The "first paired-data comparison" claim is inconsistent across sections

§2 has the precise version: "first paired-data comparison... where information content is held constant by shared-source rendering." The Abstract, Contribution 1, and Conclusion all use the unqualified version. The full-version claim should be the canonical one because Moldwin 2021 also did paired same-patient comparison; the differentiator is shared-source rendering. Currently the paper claims a precise novelty in one place and a broader (and contestable) novelty in three others.

### 2.8 Author affiliation discrepancy

The cover page reads "metricHEALTH" with email `tirtheshjani@gmail.com`. The original May draft used `tirthesh@metrichealth.ca`. If the personal email is intentional pending employer IP clearance, this is fine, but consider adding a footnote: "Author submits this work in a personal research capacity; institutional affiliation pending IP clearance on associated dataset release." A reader who notices the mismatch will otherwise wonder.

## 3. Minor items

- **Typo (§4.9):** "ungiessable" -> "unguessable."
- **Abstract (§1) restructure:** The Abstract now carries the no-retrieval decomposition (+15.4 / +10.1 / +8.2 pp) and the templated-narrative result. It is dense. Consider splitting the Results paragraph at "On a synthetic adherence label..." so the feature-arm result has its own block.
- **Contribution list:** 6 items, with item 4 now containing two findings (representation dissociation + templated ablation). Consider splitting into 4a and 4b, or promoting templated-narrative to its own item 5 (current item 5 -> 6, current item 6 -> 7).
- **§4.10:** "below -2 pp, the threshold below which we would conclude that LLM-specific narrative features carry meaningful extra signal." The -2 pp threshold is asserted without justification. State the pre-registration source or call it a post-hoc convention so the reader can evaluate.
- **§5 (Discussion, format vs LLM):** The hybrid narrative direction ("deterministic table-like phrasing for date-arithmetic families and LLM prose for aggregation families") could be moved to the future-work list in §8 with a clear hook.
- **Reproducibility (§7):** The two release tags (v1 and v2) and the v2 freeze manifest (SHA-256 2358e828...) are excellent. The GitHub URL placeholder + "email author for private link" disclosure is reasonable for a preprint but flag it for the version of record.
- **§6 Limitations:** The "Single answer LLM" entry should now reference §4.10. Templated narratives use no LLM at all in the narrative-generation step and still match A on the answer LLM, which is partial robustness evidence on the generation side. The answer-LLM dependence remains, but the entry could be sharpened to reflect what was tested.
- **Table 12:** Use a consistent decimal convention. Some cells show two decimals ("+10.21 pp"), others show one ("+3.43 pp"). Pick one.

## 4. Summary

The revision converted a solid-but-overclaiming preprint into a substantively stronger paper. The two new experimental arms (System N and System A-T) are well-designed, well-reported, and directly answer the attribution questions the prior version left open. The remaining items are framing and presentation, not methodology.

If the author addresses items 2.1, 2.2, 2.3, and 2.7 above (template-narrative findings foregrounded, Methods previews the new arms, novelty claim consistent), this is ready for arXiv as-is. For JAMIA, items 2.5 and 2.6 plus a real-data or regimen-impact-modeled validation pass would close the remaining gap.

The work is now a credible reusable benchmark contribution for the specialty-pharmacy QA subfield. The reproducibility infrastructure (v1/v2 release tags, freeze manifests, dual cache directories, dedicated scripts for each arm) is exemplary and deserves separate notice.
